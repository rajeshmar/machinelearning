## How to use 😄

### Option A: Open the single file (recommended)

1. Open `ml_mastery_single.html` in your browser.
2. Use the left sidebar to jump between modules.

### Option B: Use the shell (loads module files)

1. Open `shell.html` in your browser.
2. Click modules in the sidebar (it loads `moduleX.html` files).

## What you’ll learn (outcomes) 😎✅

You’ll go from **core fundamentals** → **deep learning** → **modern GenAI** → **deployment & responsible AI**, including:

- AI vs ML vs Deep Learning
- The ML workflow (problem framing → data → model → evaluation → iteration)
- Classic ML algorithms + the practical data science toolkit
- Neural networks fundamentals + why activation functions matter
- CNNs (vision), RNNs/LSTMs (sequences), and how they differ
- Feature engineering and why it often beats “more complex models”
- Evaluation concepts (metrics, curves, tradeoffs) and avoiding common mistakes
- Ensembles and why “many weak learners” can outperform “one strong learner”
- Generative AI foundations and the transformer shift
- BERT vs GPT, embeddings, attention (Q/K/V), and core NLP concepts
- Prompt engineering, RAG vs fine-tuning, and when smaller models win
- RLHF, multimodal systems, hybrid AI, XAI, ethics, AutoML, deployment basics
- Frontier ideas (quantum ML, neurosymbolic AI, future directions)

## Troubleshooting 🧰🙂

- **Best experience:** desktop browser (Chrome/Brave/Edge) 💻
- Some modules load external libraries via CDN (Tailwind / Chart.js / icon sets). If your environment blocks external scripts, **styling and interactive elements may be limited** (but content should still be readable) 🙂
- If you see blank/partial content, try opening via a local server instead of `file://` (some embedded behaviors are restricted in file mode). ✅
